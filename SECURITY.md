# Security policy

If you find a vulnerability **in this tool** (for example, the scanner executing, fetching or
leaking content from a scanned repository, or printing a secret unmasked), please report it
privately through GitHub → *Security* → *Report a vulnerability* on this repository. Do not open
a public issue.

Please do **not** report vulnerabilities in third-party MCP servers here. Contact the server's
maintainer or its security policy instead.
